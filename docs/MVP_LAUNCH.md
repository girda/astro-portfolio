## История устранённого сбоя публичного Pixel
На скриншоте пользователя Turnstile успешен, затем API возвращает 502. Один отдельно разрешённый минимальный запрос локальным ключом к OpenAI вернул 200 — это не проверяет секрет Worker. Подготовленная безопасная диагностика опубликована 29.10 по поручению пользователя, версия 3ca25a54-c1d3-495e-a1d6-a9fa282b4846. Сервер сохраняет Siteverify и лимиты; запрос без токена получает 403 verification_failed. В управляемом браузере challenge не завершился; ручная отправка запрошена. Причина 502 подтверждена: провайдер вернул HTTP 401 (авторизация). Пользователь подтвердил настоящий ответ после обновления ключа; Invisible принят реальным запросом без галочки. Следующая проверка — три демосценария и путь обращения. [Диагностика](audit/pixel-provider-2026-10-29.md).
