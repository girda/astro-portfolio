Одна основная задача → конкретный результат → релевантная проверка → отдельный локальный коммит. Список «сейчас / дальше / позже» ведём в docs/TASKS.md. После проверок и коммита — push по постоянному поручению Артёма от 28.10.2026. Отдельные server deploy и merge требуют отдельного поручения. Новые идеи не расширяют минимальный запуск автоматически.
