## Блок Pixel — ожидает согласования
Предложение: три примера вместо общих описаний — кафе (выбор + аллергены + демокорзина), автосалон (подбор + запрос тест-драйва), СТО (потребность + черновик заявки). Показывать короткий диалог, результат и переход к самостоятельной пробе. Примеры не выдавать за реальные записи/заказы; свободный ввод сохраняется. Пользователю отправлен вопрос с вариантом заменить автосалон на мастера по дому.
