# Задание для Codex — интеграция демо ХЛІБНИЙ в HIRDA Astro portfolio

## Контекст

Рабочий репозиторий: `girda/astro-portfolio` (локальная копия, которую пользователь открыл в VS Code/Codex).

Источник демо в архиве рядом с этим файлом: `khlibnyi-reference-astro/` (главные файлы `src/components/Homepage.astro`, `src/pages/index.astro`, `public/styles.css`, `public/app.js`, `public/assets/*.svg`). Это независимая концептуальная реконструкция дизайна, а не официальный сайт бренда. Встроенная интерактивная версия — `public/preview.html`.

**Задача: самостоятельно интегрировать этот проект в существующее портфолио, выполнить правки и тесты, оставив удобную структуру для дальнейшей совместной работы. Не ограничиваться рекомендациями — реализовать изменения в коде.**

## Основные требования

1. Вначале изучи текущие `AGENTS.md`, `README.md`, `scripts/projects.mjs`, `scripts/build.mjs`, `apps/portfolio/src/data/projects.ts`, `apps/portfolio/src/data/project-presentation.ts`, `apps/portfolio/src/i18n/translations.ts`, `apps/portfolio/src/components/PortfolioPage.astro`, `apps/portfolio/src/components/ProjectCard.astro` и `apps/lindenhof/` как пример отдельного демо.
2. Создай `apps/khlibnyi/` как отдельное Astro-приложение по примеру других демо. Перенеси из исходника макет, стили, JS и SVG, сохрани максимальную визуальную точность, анимации, функциональность меню и мобильную версию. В рабочей папке должен остаться читаемый исходный код, чтобы я мог дальше менять дизайн через Codex.
3. Порт 4332 для `npm run dev` и `npm run preview` (если не занят). Настрой `astro.config.mjs` аналогично `apps/lindenhof/`: `site: process.env.SITE_URL`, `base: process.env.SITE_BASE || '/'`, `trailingSlash: 'always'`.
4. Согласуй зависимости с текущим монорепозиторием (сейчас другие демо используют Astro 7.x и Node >=24), не устанавливай глобальные пакеты, не меняй версии других приложений без причины. Создай/обнови lockfile.
5. **Критически важно для GitHub Pages:** избегай абсолютных путей `/app.js`, `/styles.css`, `/assets/*.svg`; правильно применяй `import.meta.env.BASE_URL` или эквивалентную базу. Проверь URL картинок, атрибуты `data-fallback`, загрузку JS/CSS, favicon и шрифтов на `/astro-portfolio/demos/khlibnyi/`, локально — на `/`.
6. В `scripts/projects.mjs` добавь `khlibnyi` в `DEMO_APPS` (и автоматически в `BUILD_APPS`), чтобы корневая сборка публиковала его в `dist/demos/khlibnyi/`. Не сломай текущие пути остальных сайтов.
7. В `apps/portfolio/src/data/projects.ts` добавь идентификатор `khlibnyi`, имя `ХЛІБНИЙ`/`KHLIBNYI`, статус `demo`, категорию кафе/пекарня и собственную группу `food` (или другую согласованную с текущей структурой). Обнови union-тип группы, если нужно, и включи порт 4332. Маршрут должен корректно формироваться `projectHref`.
8. В `apps/portfolio/src/data/project-presentation.ts` добавь описания проекта на de/ru/en. В `apps/portfolio/src/i18n/translations.ts` добавь проект в списки на все три языка. Обнови фильтры проектов в `apps/portfolio/src/components/PortfolioPage.astro`, чтобы проект был доступен как в «Все проекты», так и в категории «Еда / кафе». Проследи, чтобы фильтрация и порядок карточек остались рабочими.
9. Добавь качественную карточку/превью ХЛІБНИЙ в портфолио в соответствии с существующими правилами ProjectCard. Можно использовать приложенный десктопный скриншот как референс, однако превью не должно ломаться из-за отсутствия чужого изображения. Не вливай CSS демо в глобальные стили портфолио.
10. В самом демо оставь примечание о концепте/неофициальном проекте и НЕ представляй его как заказную работу для Хлібний. Используются сторонние hotlink-фотографии Unsplash и публикаций, имеющие потенциальные ограничения прав; не выдавай их за собственные и не скачивай без разрешения. В дальнейшем заменим их на лицензированные изображения.
11. Сохрани доступность мобильной навигации, поддержку `prefers-reduced-motion`, работу фильтров выпечки/кофе/десертов, анимации загрузки, бегущей строки, появления блоков, параллакса и hover. Проверь ошибки браузерной консоли, если есть возможность.
12. Проверка: отдельный `apps/khlibnyi` dev и build; корневой `npm run build` и `npm test`; если какой-либо тест падает, зафиксируй причину и исправь, если связано с изменениями. Проверь итоговый `dist/demos/khlibnyi/index.html` и пути ко всем ассетам.
13. Не изменяй Pixel, n8n, AI backend, действующие демо и общую структуру портфолио без необходимости. Не делай `git push` без моего разрешения. Покажи изменённые файлы, что протестировано и точную локальную/публичную ссылку, которая будет работать после публикации.

## Предполагаемый результат

- Локальная страница: `http://localhost:4332/`
- После публикации: `https://girda.github.io/astro-portfolio/demos/khlibnyi/`
- Карточка видна на `https://girda.github.io/astro-portfolio/` в DE/RU/EN.
- Все дальнейшие визуальные правки можно делать непосредственно в `apps/khlibnyi/`.

## Примечания

Исходник создавался под Astro ^5.16.0, а монорепо сейчас использует Astro ^7.3.5. Убедись в совместимости при интеграции. `public/preview.html` — демонстрационная standalone-страница; при необходимости исключи её из публичной сборки, чтобы не делать дубликат неофициального сайта.
