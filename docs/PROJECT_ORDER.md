# Порядок проектов в портфолио

Редактируй `apps/portfolio/src/data/project-order.json`: первый ID отображается первым, второй — вторым и так далее. Порядок одинаков для DE/EN/RU.

```json
["lindenhof", "hausbau", "barbershop", "cleaning", "autoservice", "nails", "electrical", "homeservice", "gardens", "ecohomes"]
```

- hausbau — Falkenried, новый каталог домов.
- ecohomes — Eichenhain, деревянные дома и энергия.
- Остальные ID совпадают с папками демосайтов.

Переставляй строки, сохраняя кавычки, запятые и квадратные скобки. Пропущенные известные проекты добавляются в конец автоматически. Повтор ID или неизвестное имя останавливает сборку с понятной ошибкой. Чтобы добавить новый проект, сначала зарегистрируй его в projects.ts и переводах; JSON управляет только порядком, а не созданием сайтов.

После сохранения dev обновляется автоматически; для публикации нужна новая сборка и отдельный push.
