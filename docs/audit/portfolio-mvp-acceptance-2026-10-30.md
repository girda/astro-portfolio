# Приёмка портфолио — 30.10.2026

Объём: первый этап MVP — портфолио DE/EN/RU, каталог, Pixel до активации и подготовка обращения. Публичная версия на момент проверки: 7d314c9; исправления проверены на production-сборке локально на всех трёх языках. Дизайн не меняется. Шесть демосайтов отдельно заново не принимаются этим отчётом.

## Пройдено
- Публичные главные страницы `/`, `/en/`, `/ru/`: HTTP 200; ширины 320, 390, 768, 1024, 1440 px. Нет горизонтального overflow или pageerror. По одному h1, корректный canonical языка. Видимые изображения в момент проверки без ошибок загрузки; это не проверка каждого ленивого изображения сайта.
- В 15 свежих контекстах после загрузки и прокрутки к контактам: cookies=[], localStorage/sessionStorage пусты, запросов к внешним origin нет. Общий cookie-баннер не добавлен; Pixel и карты активируются отдельно. Новые сторонние интеграции требуют повторной оценки. Это наблюдение реализации, не юридическое заключение.
- DE/EN/RU, 390 px: по шесть проектов на обеих страницах; фильтр `homes` показывает два дома отдельно от мастеров. Выбор языка содержит три правильных URL, Escape закрывает список.
- Каталог DE/EN/RU на 320/1440 px: HTTP 200, вторая страница содержит шесть карточек и `?page=2`, overflow отсутствует. Прямой URL `?category=homes` показывает только два дома.
- Hero открывает Pixel; Escape закрывает окно и возвращает фокус кнопке. На 320/390/768/1440 окно помещается в viewport. До согласия внешняя сеть не активируется. Отказ от активации сохраняет введённый вопрос. Демо открывается через существующий Pixel.
- Форма DE/EN/RU: пустая отправка невалидна; тестовые имя/текст корректно попадают в единственный параметр `text` URL WhatsApp. Переход перехвачен и прерван до запроса в WhatsApp; сообщение не отправлено. Material-подобный фокус поля имени виден через цвет границы/подчёркивание.
- Ссылки Impressum, Datenschutz и переход к Lindenhof доступны, HTTP 200. Правовые данные уже опубликованы, прежние ожидания реквизитов в исторических планах не являются текущим статусом.
- Скриншоты первого экрана 320/768/1440 просмотрены; текст и CTA помещаются. Панель активации Pixel на 320 также просмотрена.

## Найдено и исправлено
1. **Pixel, клавиатура на телефоне.** Открыть чат → начальный фокус на панели → Shift+Tab. Фокус уходил на launcher за модальным окном. Теперь начальный фокус панели/фокус вне окна направляется к первому или последнему контролу по направлению Tab. Проверены Shift+Tab, замыкание последнего → первого, Tab с панели и Escape.
2. **Мобильное меню → каталог.** Ссылка без hash вызывала `document.querySelector('')`, хотя навигация продолжалась. Теперь якорная секция ищется через getElementById только при наличии hash. Ошибка воспроизведена на публичной версии; на локальной production-сборке DE/EN/RU переход в каталог и переход к контактной секции проходят без pageerror. Меню закрывается, фон теряет inert, фокус переходит в контактную секцию.

## Границы приёмки
- Эмуляция Chromium, не настоящий iPhone/Android и не реальная экранная клавиатура. Ручная проверка на телефоне остаётся перед окончательной приёмкой MVP.
- Новый платный вызов OpenAI и обход Turnstile не выполнялись. Живые ответы/сценарии 29–30.10 описаны в pixel-scenarios-2026-10-29.md и pixel-cafe-2026-10-30.md; сегодняшние проверки окна не заменяют живой диалог.
- Тесты ошибок/повторов транспорта входят в node suite; сегодня реальный отказ провайдера не провоцировался. Публичная база заявок/реальный заказ не включались.
- Нет нового измерения Lighthouse/CWV, полной проверки контраста/WCAG или отдельного typecheck: такого script в app нет. Основная матрица использует reduced motion, обычные анимации целиком не переоценивались.
- Следующий этап: приёмка шести основных демо, затем согласование минимальной CMS кафе. Это не заявление о завершении всего коммерческого запуска.
