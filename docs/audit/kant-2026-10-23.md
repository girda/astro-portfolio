# KANT · Ink & Paper — результат и проверка

Дата: 23.10.2026. Статус: **реализовано локально, на проверке у Артёма**. Публикации, commit и push не было.

## Объём

Завершён согласованный бумажный вариант `apps/barbershop`: печать с креслом, первый экран с интерьером без ковра, услуги, салон, галерея из шести прежних фотографий, витрина ухода, этапы посещения, FAQ, контакты, отложенная загрузка карты и футер. Существующие Embla, меню и демонстрационные диалоги сохранены. Используются два шрифта: Oswald и Arimo.

Новая витрина ухода открывает консультационный demo-диалог; корзины, оплаты и отправки заявки нет. Контакты и цены — примеры; сайт явно отмечен как вымышленный салон. Превью KANT в портфолио обновлены для трёх устройств. Дизайн самого портфолио и Pixel не менялся в этом этапе.

## Команды

Из `apps/barbershop`:

```sh
npm run dev -- --background --host 127.0.0.1 --port 4322
npm run build
SITE_URL=https://girda.github.io SITE_BASE=/astro-portfolio/demos/barbershop/ npm run build -- --outDir /private/tmp/kant-production-build
```

Из `apps/portfolio`: `npm run build`.

Локальный просмотр: http://127.0.0.1:4322/ . Управление dev server: `npm run astro -- dev status`, `npm run astro -- dev stop`, `npm run astro -- dev logs`.

## Медиа и ограничения перед публичным показом

- Интерьер взят из ранее утверждённой генерации; новая натюрмортная фотография ухода сгенерирована imagegen для вымышленного KANT. Подписи сообщают об ИИ-изображениях.
- Существующие `cut-01.jpeg`, `cut-02.jpeg`, `cut-03.jpeg` сохранены по согласованному решению. Их исходные ссылки/условия в текущем `lookbook.json` отсутствуют: **перед публикацией подтвердить происхождение либо согласовать замену**. Это не разрешение использовать любые фотографии из интернета.
- Для `cut-04.jpg`–`cut-06.jpg` сохранены авторы и ссылки Unsplash из проекта; повторный полный лицензионный аудит этих материалов не выполнялся.
- У первых и третьих файлов расширение jpeg, но содержимое WebP. В браузере они работают; для Figma сделаны только технические JPEG-копии без изменения композиции. Исходники сайта не перезаписаны.
- WOFF2 взяты из утверждённого локального прототипа. Официальные SIL OFL-тексты Arimo и Oswald сохранены рядом с файлами шрифтов; ссылки — в MEDIA.md.
- Backend бронирования отсутствует намеренно. Данные примеров не предназначены для реальных заказов.
- В рабочем дереве были многочисленные чужие/предыдущие незакоммиченные изменения. Они не откатывались, задача не подтверждает готовность соседних приложений.

Следующий этап по согласованному плану: точечная проверка текущего портфолио, Pixel и письменного канала заявки. Полный редизайн отложен.
