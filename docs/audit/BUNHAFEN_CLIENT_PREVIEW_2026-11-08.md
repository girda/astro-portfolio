# Bunhafen: прототип для показа, 08.11.2026

## Изменения
- Diner → Bunhafen: собственный векторный знак и wordmark, новый маршрут, ссылки CMS и QR. Старый адрес сохранён через перенаправление.
- Компактные карточки: фото слева, красно-синие ценники справа, обычный регистр заголовков, описание и аллергены ниже.
- Во всех трёх меню выбранная категория центрируется горизонтально; категории остаются сверху при скролле. Нативная подсветка касания отключена, клавиатурный focus-visible сохранён.
- Street Food показывает фото целиком; CMS получила новый знак My Menu и отступ под ним. Скриншоты оформления в CMS обновлены.
- Техническая демоподпись убрана с основного экрана. В корзине явно указано, что тестовый заказ не отправляется на кухню. Пользователь подтвердил показ прототипа, а не запуск меню для гостей.

## Проверено
- `npm run build`: пройдено, 59 HTML страниц.
- `npm test`: 93/93. Первый запуск до пересборки получил 503 для отсутствующего нового маршрута; после сборки тест прошёл.
- `check:seo`, `check:public`, `check:legal`, `check:media`: пройдено. Это технические проверки, а не юридическая экспертиза.
- CMS cloud build и Wrangler `--dry-run`: пройдено; сервер не опубликован.
- Playwright: `/preview/`, `/preview/bunhafen/`, `/preview/pizzeria/`, CMS; 320, 390, 768, 1024, 1920, 2560, 3840 CSS px без горизонтального переполнения.
- Во всех трёх меню четвёртая категория центрируется (смещение 0 px при 390 px); после скролла categories.top = 0.
- Диалог продукта открывается по центру и закрывается Escape. Фото Street Food: object-fit contain.
- Шесть ценовых вариантов подставлены только в перехваченный браузерный HTML без записи в базу; при 320 px ценники заканчиваются на 24 px выше заголовка.
- Старый локальный адрес `/preview/diner/` перенаправляет на `/preview/bunhafen/`.
- QR-вкладка содержит Bunhafen, генератор использует новый путь (покрыто тестом).

## Ограничения
- Проверена эмуляция, не физический телефон/4K-монитор.
- Данные примерные, цены и аллергены кафе не подтверждены; заказ не передаётся на кухню.
- Локальный Astro dev на 4334 возвращает 403 для двух общих шрифтов вне корня приложения; итоговая сборка и локальная CMS загружают шрифты корректно. Скриншоты приёмки сняты в CMS на 8790.
- Название Bunhafen рабочее; проверка товарных знаков не проводилась.
- Push публикует статический сайт через существующий CI; сетевой Worker CMS отдельно не развёрнут.
