# Локальная Menu CMS — 31.10.2026

Согласовано: сначала локальная CMS, категории → продукты. Реализована первая версия; не сетевой сервис и не законченная система реальных заказов.

## Реализовано
- Отдельный apps/menu-cms: Node.js 24, встроенный node:sqlite, без новых npm-зависимостей.
- Категории: создание/редактирование названия, существующего значка меню, порядка, видимости.
- Продукты: создание/редактирование категории, названия, описания, цены, фото из локальной библиотеки, примерных аллергенов, времени, порядка и доступности.
- Один продукт → одна категория, стабильные ID. Перенос сохраняет ID. SQL foreign key запрещает продукт без категории. Физического удаления нет; скрытие обратимо.
- Общий JSON-каталог вместо данных в коде: 6 категорий / 24 продукта, цены в евроцентах. Виртуальные фильтры «Все»/«Избранное» отдельно.
- SQLite заполняется один раз; сохраняет правки после перезапуска; не затрагивает Pixel/n8n/заявки.
- Предпросмотр использует настоящую собранную страницу Street Food и её интерфейс/корзину. Убрано статическое дублирование массива продуктов в клиентском коде: текущая страница передаёт свой JSON.
- Внешний вид публичного меню не менялся. Обновлён только источник данных и путь чтения, исходные имена/цены/изображения сохранены.

## Проверки — пройдено
- 72/72 node tests: существующие 66 + контракт каталога (3) + SQLite/API (3).
- SQLite: категория/продукт, повторное открытие файла, перенос, цена, отклонение неизвестной категории и фото, rollback невалидной записи, конфликт revision.
- HTTP: чужие Host/Origin/Sec-Fetch-Site → 403, content-type → 415, отсутствующая версия → 428, некорректные данные → 400, устаревшая версия → 409, body >64 KiB → 413, неизвестный ID → 404, DELETE → 405.
- Полная сборка 13 публичных приложений. SEO/public/legal/media checks; git diff --check.
- В готовых публичных HTML/JS не найдено `8790`, `menu.sqlite` или `/api/catalogue`. Сама CMS не добавлена в BUILD_APPS.
- git check-ignore подтверждает исключение рабочей SQLite. Секреты и база не включаются в коммит.
- Браузер, временная база на 8791: создать QA Drinks → создать QA Coffee → цена 4,50 → 4,99 → reload → предпросмотр 25 карточек и правильная цена. Добавление нового продукта в корзину использует 4,99 €. Отключение категории убирает её и продукт, возвращает 24 карточки.
- Рабочая CMS на 8790 оставлена с исходными 6/24; тестовые записи в неё не добавлялись.
- Админка/редактор/предпросмотр: 320/390/768/1440 px, без горизонтального overflow, dialog помещается в viewport, без pageerror и HTTP >=400. В предпросмотре корзина исходного Chicken & Cheddar даёт 11,90 €.
- Проверка XSS во временной базе: имя с `</script><script>window.cmsInjected=true</script>` осталось обычным текстом; JSON читается, код не выполняется.
- Найден и исправлен fallback в preview: он брал production base из скомпилированного JS и давал 404. Теперь берётся адрес fallback из текущей страницы; img без src не загружает запасное фото заранее. Повторная браузерная проверка без 404.

## Ограничения
- Нет сетевой авторизации/ролей, загрузки новых фото, редактирования extras, удаления, онлайн-публикации, реальных заказов и платежей.
- Локальный сервер слушает только loopback. Проверки Host/Origin и CSP не заменяют полноценную защиту публичной CMS. Не выставлять наружу через туннель.
- SQLite — отдельный черновик. Публичная сборка продолжает читать JSON; кнопки публикации пока нет. Изменения админки не меняют GitHub Pages автоматически.
- Снимки и проверки — эмуляция Chromium, не реальное мобильное устройство. Нет нового Figma-макета CMS или полной проверки WCAG/Lighthouse; это первый рабочий интерфейс для обсуждения.

## Запуск
`npm run cms` из корня. Открыть http://127.0.0.1:8790/, затем /preview/. После изменения контента обновить preview. После изменения frontend-кода сначала npm run build.
