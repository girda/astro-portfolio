# Меню и CMS: контакты, категории, движение, 08.11.2026

## Готово локально
- Пицца/томаты разнесены по отдельным колонкам. Поворот фото учтён; при 768px видимый bounding box фото заканчивается в663px, декор начинается674px; при1024px —856/894px. На1920–3840px зазор38px. С корзины убран базилик.
- Все три меню используют одну квадратичную траекторию из31 кадра,560ms, без прежнего углового перелома. Unit test проверяет непрерывность второй разности и попадание в центр корзины. В браузере у всех трёх тем проверены длительность560ms и31 keyframe; reduced motion сохраняется.
- Клик категории прокручивает к началу блюд с учётом sticky навигации; первоначальная загрузка не принудительно прокручивается. При390px первый результат полностью расположен ниже табов.
- Общий footer с адресом, часами, телефоном и email для предложений. Данные явно вымышленные, номер недействующий и не является tel-ссылкой, email example.com не отправляет сообщения. Формы обратной связи с backend не добавлялись.
- CMS: пояснение про индивидуальный дизайн, нативный select со стрелкой для цен, showPrices сохраняется в SQLite/D1-адаптере без миграции. Старые черновики совместимы. Без цен — режим просмотра без заказа.
- Локальная CMS: «Аккаунт» с нативным dialog (Escape, центрирование); ссылки на защищённый сетевой вход и управление пользователями. Сетевой UI: users виден супер-админу в навигации, копирование ссылки регистрации.

## Ограничения
- Это прототип с общим каталогом. Viewer подходит для показа, editor меняет общий каталог; отдельных ресторанов/tenant isolation пока нет.
- Регистрация по email зависит от настройки политики Cloudflare Access; новую регистрацию в сети после этого этапа не проходили.
- Обновлённая сетевая CMS не опубликована по решению пользователя. Git push и серверный deploy — отдельные действия.
- Viewport-эмуляция не равна тесту на физическом телефоне/4K-мониторе.
- Контакты, блюда, цены и аллергены надо подтвердить перед использованием реальным кафе.
