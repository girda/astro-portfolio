# Lindenhof — сравнение автомобилей, 28.10.2026

Реализовано локально. Публикация не выполнялась.

## Поведение
- Весы в карточках выбирают/снимают модель; отдельная панель открывает сравнение.
- До трёх моделей, защита от четвёртой, удаление и очистка.
- Выбор сохраняется в sessionStorage; повреждённые/неизвестные ID отбрасываются.
- Фото, марка, кузов, место и описание взяты из существующего каталога. Отсутствующие цены и технические параметры не выдумываются.
- Переход на страницу модели; перенос модели в форму тест-драйва без отправки заявки.
- Native dialog, Escape, возврат фокуса и блокировка прокрутки фона.

## Проверки
- npm test: 54/54, включая два новых теста состояния сравнения.
- npm run build: 13 приложений успешно.
- npm run check:seo: PASS.
- Playwright: выбор 1–3, ограничение четвёртого, удаление вплоть до последнего, очистка, перезагрузка, Escape, переход на Volkswagen Golf, заполнение формы Mazda3.
- Эмуляция 320/390/768/1024/1440 px: без горизонтального переполнения окна; фото загружаются. Это не тест на физических устройствах.
- Визуально проверены desktop и mobile; исправлены высота изображений и иконка закрытия.

## Ограничения MVP
Это сравнение примеров каталога, не актуальная база наличия автомобилей. Формы не отправляют реальные обращения. Общая приёмка остальных демо, публичный Pixel и юридические страницы остаются отдельными незавершёнными пунктами MVP.
