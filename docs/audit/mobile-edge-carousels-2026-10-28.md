# Мобильные слайдеры до краёв экрана — 28.10.2026

## Результат
Общее правило packages/ui/edge-carousel.css, opt-in data-edge-carousel. На ширине до 700 px видимая область ленты занимает экран; первые/последние карточки сохраняют поля контента, промежуточные выходят за экран в обе стороны. Desktop не расширяется. Обычные сетки, вертикальные списки, формы и модалки не изменены.

Применено: два HouseCarousel Falkenried; автомобили и клиентские перспективы Lindenhof; lookbook и средства KANT; общий ReviewCarousel (KANT, KLAR, Eichenhain). Всего девять лент на пяти сайтах. Средства KANT на телефоне занимают 88% внутренней ширины, чтобы показать соседний продукт. Существующие свайп, стрелки, клавиатура, reduced motion и Embla сохранены.

В пользовательский Desktop/CODEX/AGENTS.md добавлено правило такого поведения будущих похожих слайдеров. В packages/ui/README.md описано применение внутри центрированного контейнера и snap-поля под его breakpoints.

## Проверки
- Пройдено: npm run build — все 13 приложений.
- Пройдено: npm test — 52 теста.
- Пройдено: npm run check:seo и git diff --check.
- Playwright: 320, 390, 430, 650, 768, 1440 px. 54 сочетания ленты/ширины; начало и конец проверены геометрически. На мобильных viewport ленты от 0 до ширины экрана; крайние карточки совпадают с внутренним padding с допуском 2 px, страница не переполняется.
- Дополнительно проверены промежуточные положения девяти лент на 390 px и выполнен визуальный просмотр Lindenhof. У native scroll-snap часть положений попадает точно в промежуток между карточками; это не обрезка по контейнеру.
- Это эмуляция Chromium, не проверка на реальном iPhone/Safari.
