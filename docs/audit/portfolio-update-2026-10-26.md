# HIRDA — согласованное обновление портфолио, 26.10.2026

## Изменения
- ProjectCard: все реальные устройства остаются отдельными слоями, уменьшена композиция ноутбука с запасом для наклона. Новые категории и описания девяти демосайтов в data/project-presentation.ts (DE/EN); ссылка Demo öffnen / Open demo.
- Services: три направления из согласованного предложения — Websites, Web-Apps, KI-Agenten. CMS, редизайн и сопровождение отражены в описаниях и прежнем прайсе.
- PixelExperience: отдельная секция с тремя иллюстративными примерами и кнопкой существующей живой демо. Статичные примеры явно подписаны, не имитируют ответ API.
- Плавающий Pixel и приветствие доступны на первом экране. После ухода hero из viewport скрываются через IntersectionObserver и inert. Открытая панель чата остаётся доступна. Код переименован pixel-contact.ts → pixel-visibility.ts.
- Фон: спокойные градиенты, тонкая координатная сетка и декоративные дуги. Первый экран, логотип и основная палитра сохранены. Отступы используют прежний section-space, исчезновение fixed-виджета не добавляет пустой блок.
