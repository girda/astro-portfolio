# Общий рефакторинг и интеграция Lab — 24.10.2026

## Объём
Текущий production-набор: портфолио и девять демосайтов. GitHub origin/main 4caf0da объединён merge-коммитом с существующей локальной историей; пришли WebGLLab.astro и /lab/. Конфликтов нет. Пользовательские untracked-файлы и apps/vyra не изменены, не добавлены в публичную сборку.

## Реализовано
- Общий page-lifecycle для очистки и повторного запуска при переходах Astro.
- Механика SiteMotion и ReviewCarousel вынесена из Astro в небольшие TypeScript-модули. Карусель вычисляет фактический CSS-gap, освобождает ResizeObserver и слушатели.
- DemoMenu переинициализируется без накопления обработчиков; сохраняет нативный dialog и Escape.
- Единый список приложений scripts/projects.mjs для сборки и SEO.
- Сборка собирает результат во временный каталог; ошибка любого приложения сохраняет прежний корневой dist. Регрессионный тест проверяет отказ и успешную замену в отдельном временном проекте.
- Lab: WebGL отделён от разметки, удалён неиспользуемый CSS старых карточек. Остановка вне экрана, возобновление, runtime reduced-motion, resize статичного кадра, сохранение сцены при pagehide/pageshow, освобождение ресурсов при переходе Astro. /lab/ проверяется как noindex и исключён из sitemap.
- Небольшая полировка девяти демо: сбалансированные переносы заголовков, читаемые абзацы, отступы якорей, hover кнопок каруселей, размер касания. Портфолио: переносы/интерлиньяж карточек и короткий hover SVG. Цвета, сетки и содержание сохранены.

## Проверено
- npm run build: все 10 приложений успешно, включая новую /lab/.
- npm test: 28 прежних тестов проходят; отдельный scripts/tests/build.test.mjs проходит.
- npm run check:seo и git diff --check: проходят.
- Chromium: 9 демо + портфолио + Lab на 320/390/768/1440 px: 44 комбинации без горизонтального overflow.
- 7 общих DemoMenu: открытие, Escape, повторные astro:page-load; aria-expanded обновляется после асинхронного close.
- Карусель STILL: повторная инициализация, переходы по карточкам и reduced motion.
- Lab: сцена is-ready; все шесть превью загрузились. Измерение callbacks requestAnimationFrame: есть при видимости, 0 вне экрана и при reduced motion, возобновляются после возврата. Повторная инициализация Astro успешна.
- Снимок мобильного Lab визуально просмотрен: композиция новой страницы сохранена.

## Границы
Это рефакторинг общих механизмов всего набора, а не механическая перепись каждого файла. Backend/Pixel не изменялись: пройдены существующие контрактные тесты, живые платные API и реальные заявки не отправлялись. apps/vyra — незавершённый пользовательский черновик вне публичного набора. Физические телефоны, Lighthouse/CWV и полный security/typecheck-аудит не выполнялись. Figma в этом техническом проходе не редактировалась; композиционные изменения не делались. Сохраняется предупреждение большого Three.js chunk и deprecation THREE.Clock. Push/deploy не выполнялись.
