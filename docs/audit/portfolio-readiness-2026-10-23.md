# HIRDA — проверка после KANT

23.10.2026. Объём: действующее портфолио, интерфейс Pixel и подготовка письменной заявки. Полный редизайн не выполнялся. KANT уже свёрстан в предыдущем этапе, его локальная страница повторно доступна (HTTP 200).

## Проверено

- Портфолио `/` и `/en/` работает на http://localhost:4321/ . На 320/390/768/1440 нет горизонтального переполнения; открытая панель Pixel и поле ввода помещаются в viewport.
- 15 существующих тестов `node --test apps/portfolio/tests/*.test.mjs` прошли: n8n transport, sessionStorage, ошибки/timeout, SEO URL.
- Pixel с перехваченными тестовыми ответами: Enter сохраняет фокус; повторная отправка показывает подсказку и создаёт только один запрос; следующий черновик сохраняется; ошибка HTTP 500 показывает повтор; повторная попытка восстанавливает ответ; Escape возвращает фокус.
- В локальном интерфейсе выбран transport n8n, контракт `{action, sessionId, chatInput}`. Обрабатывается массив с полем output. Реальная генерация ответов/оплата OpenAI не запускалась этой проверкой.
- Четыре категории KI-Demo доступны. Найдено и исправлено: название выбранной сферы не попадало в chatInput. Теперь стартовое сообщение содержит Café / Auto / Eco-Haus / Werkstatt. Проверено восемь сочетаний (4 сферы × DE/EN): категория передана, контракт не расширен, демосессии различаются.
- WhatsApp-форма на DE/EN формирует ссылку на существующий подтверждённый номер, включает имя и сообщение. Переход перехвачен в тесте, реальное сообщение не отправлялось.
- Локальные ссылки Lindenhof, Eichenhain, KANT отвечают HTTP 200. Cleaning, Autoservice, Nails недоступны на своих dev-портах: серверы не запускались; это не доказательство неисправности production-ссылок.
- n8n `/healthz` отвечает HTTP 200. Резервный локальный API на `127.0.0.1:8787/health` недоступен; текущий dev-чат использует n8n.
- Production build с `SITE_URL=https://girda.github.io SITE_BASE=/astro-portfolio/` прошёл; старое предупреждение Vite о чанке >500 kB осталось. Lighthouse/CWV не измерялись. Lint/полный typecheck в app scripts не настроены.
