# Pixel: публичная проверка и выход к контактам

## Публичный результат
На https://girda.github.io/astro-portfolio/ru/ в обычном Chrome через управление браузером открыто демо кафе. Ответ модели не получен: первоначально общая ошибка, при повторе ошибка проверки. В DevTools подтверждён Turnstile 300030 (generic challenge failure). Это не доказательство, что обычный посетитель получит тот же отказ. Авторизованный публичный URL API указан в GitHub variable и собранном JS. OPTIONS с Origin https://girda.github.io получает 204 и ожидаемый CORS.

Настройки Cloudflare, ключи, server-side Siteverify, домены, лимиты и Worker не менялись. Защита не обходилась. Пользователю предложена ручная проверка в обычной вкладке. Три настоящих диалога кафе/автосалон/мастер остаются непроверенными.

Источник интерпретации кодов: https://developers.cloudflare.com/turnstile/troubleshooting/client-side-errors/error-codes/ . Документация конфигурации: https://developers.cloudflare.com/turnstile/get-started/client-side-rendering/widget-configurations/ .

## Исправлено
- Ограничено ожидание загрузки Turnstile: 12 секунд; зависший сторонний скрипт не удерживает чат в busy бесконечно.
- Исключение render отклоняет Promise, разрешая нормальный повтор. После таймаута удаляются обработчики загрузки, чтобы позднее событие не создало неожиданный виджет.
- Сообщение об отказе проверки больше не просит пройти невидимую проверку; предлагает обновление страницы либо прямой контакт.
- При любой ошибке ответа рядом с повтором доступна ссылка к контактам. Закрывает чат, возвращает прокрутку, переводит фокус в имя. DE/EN/RU.
- Figma PuicLapgF9vnSyRn8xofU8: редактируемое состояние ошибки 63:1330 из существующих компонентов сообщения и действий. Визуально проверено.
