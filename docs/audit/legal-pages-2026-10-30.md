## Реализовано
- Общие немецкие /impressum/ и /datenschutz/ в стиле портфолио. Собственный canonical, без вымышленных переводов/hreflang; на этих страницах нет Pixel и внешних подключений.
- LegalLayout использует BaseLayout с выключенной анимацией текста для удобного чтения. Обычные страницы сохраняют поведение по умолчанию.
- Ссылки из SiteFooter и общего DemoNotice: проверены53 страницы с футерами. Демопометка сохраняется; env-заглушка LEGAL_PAGES_READY больше не нужна.
- Datenschutz описывает GitHub Pages, реальные контакты Gmail/WhatsApp, добровольный Pixel, Cloudflare Turnstile/Worker, OpenAI store:false, технические логи, browser storage, активацию/остановку OSM и внешние маршруты Google. Публичная n8n/SQLite-интеграция не заявляется.
- В Pixel явное объяснение добровольного согласия и ссылка на полные сведения. После активации доступно завершение с reload. Reload отменяет разрешение на новые запросы в интерфейсе и очищает память вкладки, но не отзывает уже обработанные провайдерами данные.
- Автоматический npm run check:legal включён в CI: наличие реальных страниц и реквизитов, canonical, отсутствие placeholder/чата в legal HTML, правильный base ссылок из всех построенных футеров.
