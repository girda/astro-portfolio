# Lindenhof — уточнения интерфейса, 26.10.2026

Готово локально к проверке, без публикации. [Открыть сайт](http://127.0.0.1:8762/astro-portfolio/demos/lindenhof/).

## Изменения

- Desktop-подменю трёх уровней открываются по hover, закрываются с небольшой задержкой. Native details/summary оставлены для клавиатуры и touch. Повторные ссылки-заголовки «… im Überblick» удалены.
- Путь к страницам моделей доступен через Fahrzeuge → Marken; дополнительно картинка, название и кнопка каждой машины ведут на её страницу. Finanzierung → Kauf & Finanzierung открывает страницу финансирования, Service → Service im Überblick — сервис.
- Машины занимают 90% области фото, по наведению плавно увеличиваются до 99% за 750 ms. Ранее добавленная смена ракурсов сохранена.
- Фильтры используют начертание 400. Варианты подбора стали компактными, высотой 44 px, расположены в строку с переносом. Рядом — векторная иллюстрация автомобиля в фирменном зелёном.
- Видео: белые SVG play/pause на полупрозрачных круглых кнопках, работающие custom controls. Автоматическое muted-воспроизведение остаётся по прежним правилам.
- Первый экран телефона/планшета использует отдельную вертикальную композицию, выбранную через picture/source до 1024 px. Фото показывается с object-fit:contain. На стандартном телефоне — фото, затем текст/CTA; на низком экране до 700 px высотой — текст/CTA перед фото. Планшет — две колонки. Desktop сохраняет широкую фотографию.
- Header закреплён с постоянным местом в потоке; сворачивание не меняет расположение секций. Удалено двойное применение scroll-padding и общего scroll-margin. Drawer закрывается и возвращает фокус до запуска прокрутки.
- Появление основных блоков сдвигает их слева/справа/снизу. Добавлены hero-анимации; reduced motion отключает движение. Крупные контейнеры управляют появлением без двойной анимации вложенных элементов.
- Устаревшие правила мобильного Lindenhof удалены из общего mobile-heroes.css: адаптивность этого приложения теперь находится в его собственных стилях.
- Обновлены три превью Lindenhof в портфолио.
