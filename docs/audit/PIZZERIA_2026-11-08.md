# Forno & Basilico — проверка 08.11.2026

Этап: адаптация утверждённого итальянского референса. Готово к визуальной проверке,
без заявления о пиксельной идентичности сгенерированной картинке.

Предпросмотр сборки: http://127.0.0.1:8800/astro-portfolio/demos/streetfood/pizzeria/.
Разработка: http://localhost:4334/pizzeria/.

## Изменения

- Отдельный компонент марки: векторная кирпичная печь, огонь, надпись и зелёные детали.
- Двухрядная красная шахматная лента. Пицца перекрывает край ленты, томаты отделены от неё.
- Бумажный фон, базилик, зелёный штрих, типографика и красные разделители по референсу.
- На телефонах до 700 px hero скрыт: меню начинается с категорий и карточек.
- Сердечко и добавление оформлены в одной системе, сохранены подсказки аллергенов.
- Окно блюда: целое фото, аллергены до пожеланий, отступ под textarea над кнопками заказа.
- В статическом общем каталоге теперь 30 продуктов, включая 4 пиццы с разными фото.
  Добавлены Diavola и Funghi; Bufala получила отдельное изображение.
  Три фотографии сгенерированы для проекта, прозрачность сохранена; происхождение записано.
- Новая тема ограничена селекторами data-appearance=pizzeria. Файлы CMS не изменялись.

## Результаты проверок

Пройдено:

- npm run build.
- npm test: 88/88. Контракт проверяет четыре разные фотографии пиццы и существование файлов.
- npm run check:media: 220 ресурсов, 5 полных лицензий; проверка не юридическое заключение.
- npm run check:public: 58 HTML-страниц.
- git diff --check.
- Playwright/Chromium: 320×760, 390×844, 430×932, 700×1024, 768×1024,
  1024×900, 1440×1000, 1920×1080, 2560×1440, 3840×2160 без горизонтального переполнения.
  Ширина внешней рабочей области ограничена 1280 px на больших экранах.
- Поиск «funghi» оставляет одну карточку; категории сдвигаются на 0 px при открытии поля.
  Escape закрывает поиск. Поле раскрывается маской, без растягивания букв.
- Избранное, добавление Diavola, корзина и сумма 13,90 € работают; Escape закрывает диалог.
- Траектория добавления заканчивается в центре корзины: измеренный сдвиг
  x=107,9766 / y=282,6484 CSS px совпал с координатами назначения. При reduced motion
  летящий элемент не создаётся. Настоящая передача заказа не проверялась и не подключена.
- Иконки аллергенов открывают подсказки по нажатию. Подсказка больше не блокирует карточку.
- На 320 px последний таб заканчивается около 302 px: внешнее поле около 18 px сохранено.
- В конце прокрутки диалога 390 px нижняя граница textarea — 699,67 px,
  панель действий начинается на 729,67 px: свободный отступ 30 px.
- Краткая регрессия Diner: собственный логотип, 6 видимых бургеров, корзина скрыта.

Не проверено / ограничения:

- Эмуляция в Chromium не заменяет физический телефон, Safari и реальный 4K-монитор.
- CMS оставлена как просил пользователь: её локальная SQLite-база не мигрировалась,
  существующий старый каталог без пицц автоматически не заменяется новым seed.
  Для просмотра пицц использовать отдельную ссылку сборки выше.
- Реальные цены, рецептуры и аллергены должен подтвердить владелец; данные пока примерные.
- Отдельный серверный deploy Cloudflare не выполнялся. CMS-превью картинок не обновлялось.
