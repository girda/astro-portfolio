# Portfolio — каталог и редакция текстов, 28.10.2026

## Реализовано
- Общий `ProjectGallery` для главной и каталога. По 6 работ на страницу; единый порядок из `project-order.json`.
- Дома (`hausbau`, `ecohomes`) отделены от мастеров/сервисов. Фильтр применяется до пагинации; изменение категории возвращает на первую страницу.

- У кнопки Pixel удалена стрелка, подпись центрирована.
- Стандартная обводка текстовых полей заменена цветом границы и подчёркиванием; у checkbox/radio/range доступный фокус сохранён. По прямому поручению обновлён общий `Desktop/CODEX/AGENTS.md`; личные сведения в репозиторий не добавлялись.
