# CMS: работа с категориями и продуктами — 01.11.2026

Пользователь выбрал улучшение существующих категорий/продуктов вместо экспорта или новых фото. Объём — локальная CMS; публичное меню, данные SQLite и схема БД не менялись. Исходное состояние кода: a940d7d.

## Реализовано
- Быстрое скрытие/показ продукта с сохранением через существующий API. UI меняется только после успешного ответа. Фильтр «Видны в меню» учитывает выключенную категорию.
- Создание копии через редактор: предзаполнены данные и фото, новый ID создаёт сервер только после сохранения. Старая запись не перезаписывается.
- Поиск по категории/названию/описанию, фильтр видимости, сортировка по названию и числовой цене. Сортировка списка не меняет порядок меню.
- Новая категория выбирается автоматически; создание/перенос продукта переводит список в нужную категорию и снимает старые фильтры.
- Понятные подписи восьми существующих фото. Новые фото не загружаются.
- Отказ от закрытия оставляет черновик. Предупреждение о несохранённых изменениях при закрытии/уходе, блокировка повторных действий во время запроса, таймаут 12 секунд и понятная ошибка соединения.
- Восстановление после 409 без потери введённого: независимые поля объединяются; при конфликте одного поля показано предупреждение, сохранение только явное. Названия категорий в редакторе обновляются.
- Возврат фокуса после действий. Если скрытая строка исчезает из фильтра, фокус переходит к заголовку списка.

## Проверки
- **Пройдено:** 74/74 node tests. Два новых теста: объединение независимых/пересекающихся изменений, фильтрация/сортировка с учётом скрытых категорий без мутации исходника. HTTP-тест проверяет выдачу клиентского модуля с корректным MIME.
- **Пройдено:** node --check для admin.js, editor-state.mjs, server.mjs; git diff --check.
- **Пройдено, браузер с изолированной БД в памяти на 8792:** скрыть/вернуть Chicken; копия → QA Copy 9,25 €; исходная запись отдельная; отмена закрытия сохраняет «Unsaved QA», подтверждение закрывает.
- **Пройдено:** сортировка цены в выбранной категории 9,25 / 11,90 / 12,90 / 13,90 / 13,90 / 14,90 / 16,90 €. Пустой поиск и сброс фильтра.
- **Пройдено:** две независимые правки: пользователь меняет цену на 13,50 €, другая вкладка скрывает продукт. После 409 и обновления черновика сохранены цена 1350 и available=false.
- **Пройдено:** две вкладки меняют цену. При обновлении редактор оставляет пользовательские 14,50 € с предупреждением «Цена»; база остаётся 1500 до отдельного сохранения. Обновление черновика само не записывает его в БД.
- **Пройдено:** прерывание PUT через browser route.abort оставляет прежнюю доступность и показывает сообщение о соединении. После повторной попытки скрытие работает. Если строка ушла из фильтра, фокус на products-title.
- **Пройдено:** создание QA New Category при старом поиске выбирает категорию и очищает поиск; новый продукт наследует категорию; перенос в coffee открывает Kaffee и показывает сохранённый продукт.
- **Пройдено:** 320/390/768/1440 px, editor в viewport, нет pageerror, HTTP >=400 и горизонтального overflow. Эмуляция Chromium, не реальные устройства.
- **Пройдено:** рабочая CMS на 8790 перезапущена без сброса SQLite; чтение вернуло revision=1, 6 категорий / 24 продукта. Тестовые записи туда не вносились.

## Границы
Проверка локальной CMS по навыку hirda-website-qa. Полная сборка 13 публичных приложений локально повторно не запускалась: их код не менялся, CMS не имеет отдельного build/typecheck и не входит в публичный BUILD_APPS. Push запускает обычный CI. Нет нового WCAG/performance/security-аудита или Figma-макета. Реальный beforeunload зависит от браузера и пользовательского взаимодействия; основной сценарий Close/Escape проверен отдельно. Ожидание 12 секунд вручную не воспроизводилось, проверен быстрый сетевой отказ.

Экспорт, публикация, авторизация и загрузка фото не включены. Текущий локальный сервер не предназначен для размещения в интернете.
