# Bunhafen и My Menu, 08.11.2026

## Изменения
- Новый оригинальный векторный знак Bunhafen: рисованный бургер с крыльями и красной лентой, компактные боковые штрихи; файл в реестре происхождения обновлён.
- С1100px каталог бургерной в3 колонки, на планшете2, телефоне1. Надписи PREIS/граммовка опущены на5px внутрь красной части. Ширина композиции ограничена и на4К.
- CMS: собственный бирюзовый знак меню-свитка, отдельная надпись убрана, хлебная крошка сверху удалена. Профиль снизу с person-icon и буквой email; локально показан L, потому что облачная личность отсутствует.
- История: серверный поиск по всем записям, тип/действие/автор/изменённое поле/диапазон дат, сортировка, страницы10/20/50, счётчик. Фиксированная верхняя ревизия сохраняет позиции при новых событиях.
- Интерфейс CMS DE/EN/RU, по умолчанию немецкий, ручной выбор сохраняется. Контент блюд остаётся исходным. Смена языка сохраняет раздел и спрашивает о несохранённых правках в собственном нативном dialog.
- Широкий компактный редактор: поля в сетке, аллергены иконками в строку с title и доступными именами, флаг подтверждения состава сохранён.

## Ограничения
- Физические телефон/4К-монитор не проверялись: использована эмуляция viewport.
- Для6 вариантов, длинных текстов и небольших экранов вертикальная прокрутка редактора необходима. Нативные окна выбора файлов/дат используют язык ОС/браузера.
- Даты фильтра истории — UTC. Это JSON-поиск для текущего объёма CMS, не отдельный полнотекстовый поисковый сервис.
- Пользовательские названия блюд, текстовые составы и исторические значения автоматически не переводятся.
- Обновления сетевой CMS пока не опубликованы по ранее принятому решению пользователя. Git push не является deploy Worker.
