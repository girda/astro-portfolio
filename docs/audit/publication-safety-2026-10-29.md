# Публикация: технические исправления после аудита

29.10.2026. Репозиторий astro-portfolio, 13 приложений. Это технический этап, не юридическая приёмка. Немецкие правовые черновики и личные реквизиты владельца находятся отдельно в локальном рабочем каталоге; не публикуются этим коммитом.

## Изменения

- Все статические JS-формы в активных шаблонах имеют `method="dialog"`: без JS сетевой GET/POST не возникает. Обработчики JS продолжают явно предотвращать стандартное действие и показывать локальную сводку либо готовить WhatsApp. Динамическая локальная lead-card использует ту же защиту.
- ReturnVisit больше не подключается. Автоматическая запись `hirda:last-visit` прекращена. Старые данные уже посещавшего браузера не удаляются этим этапом; их можно очистить через настройки сайта.
- Сравнение домов/авто, избранное и демокорзина больше не записывают пустое начальное состояние при одном открытии страницы. После явного действия выбор сохраняется, как раньше; чтение прежнего выбора сохраняется.
- Manrope и Oswald Хлібний подключены локально. Manrope получен из официального google/fonts, закреплён commit b31870aff700ab7a1d74fa0c6887d95beb9e0037. Лицензии, источники и SHA-256: `apps/khlibnyi/public/fonts/SOURCES.json`.
- KANT, WERKRAUM и Eichenhain используют общий ExternalMap: OSM подключается после информирующей кнопки, скрытие удаляет src frame. Lindenhof сохраняет Leaflet/три точки и получает такую же ручную активацию/остановку. Google остаётся внешним маршрутом, а не автоматически загружаемым iframe. Активация не запоминается между посещениями.
- Новый DemoNotice поясняет независимый демонстрационный характер проектов. Legal-ссылки подготовлены под общий root, но скрыты до готовности настоящих страниц (`LEGAL_PAGES_READY`). Этот флаг нельзя включать до добавления/проверки маршрутов и текстов. Фиктивные кнопки Impressum/Datenschutz Lindenhof удалены.
- Для KANT созданы три новые фотографии вымышленных образов; для Хлібний — пять изображений помещения/фасада/продуктов, а coffee/croissant взяты из собственных ранее созданных Street Food assets. Hotlink-загрузки Village, Kyivmaps и Unsplash из главной Хлібний заменены локальными файлами.
- Исходные три KANT-снимка с неизвестным происхождением и celebrity-архив исключаются из **общего публичного dist** через `scripts/public-assets.mjs`. Они остаются в исходниках/истории Git и в отдельном app dist, который не следует публиковать отдельно без той же фильтрации. Это не удаление из публичной истории GitHub и не ретроактивная очистка уже скачанных материалов.
- CI после сборки выполняет `npm run check:public`: отсутствие сетевого fallback форм, Google Fonts, return-visit записи и исключённых архивов в общем dist. Это ограниченные технические утверждения, не автоматическая правовая проверка.

## Проверка

- Полная сборка: 13 приложений; SEO и public-safety проверяют 54 HTML.
- Unit/regression: изолированная сборка сохраняет прошлый результат при сбое, фильтрует архив и сохраняет исходник; проверены небезопасные default/POST формы и formmethod override. Проверка имён файлов не является проверкой лицензий.
- Браузер, JavaScript выключен: portfolio RU, Lindenhof, Eichenhain, Falkenried, KLAR, WERKRAUM, STILL, HAUSWERK. Прямой submit оставляет URL страницы неизменным. В первом проходе один navigation request принадлежал iframe старой Google-карты; он не являлся отправкой формы. После замены карты сетевой сценарий проверяется отдельно.
- Контактная форма с JS сохраняет кириллицу, тему и сообщение. Переход wa.me перехвачен локальной HTTP-фикстурой; настоящего сообщения не отправляли.
- Карты четырёх приложений, эмуляция390px: перед кнопкой 0 запросов OSM, после кнопки есть загрузка, после скрытия нет активного src/Leaflet; повторная активация должна оставаться возможной. В этих состояниях переполнения страницы нет.
- Локальный Pixel с тестовыми SDK/API: перед активацией API0/SDK0, отказ — API0/SDK0 и возвращённый текст; подтверждение — API1/SDK1. На320×568 кнопки доступны без overflow. Это HTTP-фикстура, не подтверждение ответа OpenAI.

## Что остаётся открытым

1. Новый Worker-сценарий кафе подготовлен и прошёл тест инструкций/dry-run; отдельная публикация запрошена. Prompt не гарантирует, что посетитель никогда не введёт настоящие данные о здоровье. Это демонстрация вымышленных заказов, не готовая система обработки медицинских сведений ресторана.
2. Impressum/полная Datenschutz: локальные черновики с подтверждёнными реквизитами, ещё нужна окончательная редактура и проверка оснований/договоров/сроков провайдеров. Placeholder-страницы не опубликованы.
3. Старые BMW/Mazda/Porsche assets и соответствие видео Pexels требуют дальнейшей пофайловой проверки происхождения. Реальный бренд Хлібний требует отдельного решения о переименовании/разрешении.
4. Старые портфолио-превью и скриншоты в документации/Figma могут содержать прежние изображения. Замена live-assets не очищает эти производные ресурсы автоматически; публичные превью проверяются следующим этапом.
5. Подтверждение privacy-текста не заменяет правовую оценку. Контракты/AVV, log retention, transfer mechanism, opt-in/ZDR и реальные устройства в этом техническом этапе не подтверждались.
