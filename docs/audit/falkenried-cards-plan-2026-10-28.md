# Falkenried — карточки и план, 28.10.2026

## Реализовано
- Один `HouseCard` на главной (оба слайдера), в каталоге и похожих домах. Упрощённая альтернативная разметка удалена; стили карточки общие.
- Сравнение в карточках, шапке и деталях использует SVG весов из общего набора.
- 3D-иллюстрация открывается в native dialog внутри сайта: изображение целиком, подпись, закрытие, Escape, возврат фокуса. Новая вкладка не нужна.
- `FloorPlan.astro`: отдельные схемы этажей с окнами, проходами, мебелью, номерами и читаемой легендой. Этажи действительно различаются, для одноэтажных домов нет лишнего переключателя и лестницы. Это схема вдохновения, не план конкретной модели и не рабочий чертёж.
- Hover у действий карточек, сравнения/избранного, типов кнопок, табов, фильтров, ссылок и сервисов. Reduced motion сохранён.
- Фокус текстовых полей в стиле Material: граница и подчёркивание; клавиатурный фокус не удалён.

## Проверено
- `npm test`: общий набор 41 PASS; текущие тесты фильтра/сортировки домов пройдены.
- `npm run build`: все 13 приложений. Falkenried — 8 страниц.
- Playwright на 320, 390, 768, 1024, 1440 px: нет горизонтального переполнения; легенда видна, схема масштабируется без искажения.
- Два этажа переключаются; окно 3D открывается, удерживает фокус, закрывается Escape и возвращает фокус к триггеру.
- Сравнение и hover проверены на production-сборке с префиксом GitHub Pages. Реальных заявок не отправляли.
- Физические устройства и Lighthouse не проверялись.
