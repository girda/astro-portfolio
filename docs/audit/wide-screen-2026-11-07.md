# Проверка больших экранов до 4K — 7 ноября 2026

## Объём и среда

Локальная публичная production-сборка, Chromium через Playwright. Главные страницы portfolio (RU), barbershop, cleaning, autoservice, nails, lindenhof, ecohomes, hausbau, khlibnyi, streetfood, electrical, homeservice, gardens. Дополнительно локальная CMS и Diner/Pizzeria. Проверены 1920×1080, 2560×1440, 3840×2160 CSS px. Это эмуляция viewport, не физический 4K-монитор. Для снимков основных страниц включён reduced motion, чтобы оценивать завершённую композицию.

## Исправления

- Единый слой `packages/ui/wide-screen.css`: ограничение сверхшироких hero до 1920 px с центрированием; фон страницы остаётся на всю ширину. Существующие контейнеры текста сохранены.
- Eichenhain: hero ограничен 1040 px по высоте вместо 2064 px на 4K.
- STILL: расчёт полей внутри hero теперь учитывает сцену шириной 1920 px; исправлено сжатие текста и изображения из-за расчёта от ширины монитора.
- KANT: ограничены header, hero и карточки услуг; другие секции уже имели ограничение ширины.
- Портфолио: ограничена сцена первого экрана; изображение сохраняет пропорции через object-fit вместо растягивания.
- CMS: центрированная рабочая область до 1920 px, навигация рядом с контентом, таблица остаётся ограниченной 1700 px. Предпросмотры меню используют существующую ограниченную ширину.
- Правило 4K записано в корневой AGENTS.md и общие правила пользователя. Изменения больших экранов работают только выше 1920 px; мобильные правила не заменены.

## Результат

Пройдено: 39 сочетаний публичного приложения и ширины, плюс 9 сочетаний CMS/дополнительных меню и ширины — без горизонтального переполнения документа. После отдельных исправлений STILL, KANT и портфолио повторно проверены на 4K. Визуально осмотрены снимки всех главных страниц. Проверены геометрия, ограничения hero и рабочей области CMS; полноценная повторная приёмка всех бизнес-сценариев и всех внутренних страниц в этот этап не входит.

`npm run build` — успешно (13 приложений).
`npm test` — 84/84 успешно. Устаревшая проверка размера seed-каталога обновлена под ранее добавленные итальянские блюда (28 продуктов, 9 категорий).
`node apps/menu-cms/cloud/build.mjs` — успешно.
