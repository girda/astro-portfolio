# Lindenhof: стабильная анимация на GSAP

Дата: 26.10.2026. Проверено локально на http://localhost:4326/ и /service/.

## Изменения

- GSAP 3.15.0 установлен только в приложении Lindenhof.
- Локальный SiteMotion заменяет общий WAAPI-обработчик. Остальные приложения сохраняют прежнее поведение.
- Причина мигания: ранее уже отображённый элемент при IntersectionObserver вновь начинал с opacity .16 и смещения. Теперь начальное состояние задаётся только текстовым блокам ниже экрана, до появления. ScrollTrigger проигрывает эффект один раз: 16px, 550ms, power2.out, без задержки. После завершения inline opacity/transform очищаются.
- Первый экран, изображения, карта, формы и крупные контейнеры не перемещаются при прокрутке.
- Выезд/закрытие меню, desktop-подменю, индикатор и содержимое табов управляются GSAP. Старые CSS keyframes удалены, новая анимация заменяет предыдущую.
- Тайминги и easing находятся в `apps/lindenhof/src/scripts/motion.ts`; табы выделены в `ownership-tabs.ts` с очисткой слушателей, ResizeObserver и tween при повторной инициализации.
- У машин сохранён единственный CSS zoom .90 → .99 без подмены изображения. Шапка и простые hover-состояния сохраняют CSS transitions; вращение декоративных шестерёнок остаётся CSS-анимацией. Эти эффекты не конкурируют с GSAP за свойства элементов.
- Компоновка и статический дизайн не изменены, изменения статичных кадров Figma не требуются.

Ограничения: браузерная эмуляция, реальные телефоны не проверялись. Полный typecheck/lint в Lindenhof не настроен; build не заменяет typecheck. В dev остаётся отдельный 404 `/favicon.ico`, не связанный с анимацией. Корневая сборка сообщает прежнее предупреждение о крупном chunk портфолио. Push и публикация в этой задаче не выполняются.
