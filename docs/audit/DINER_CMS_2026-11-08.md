# Diner + CMS: проверка 08.11.2026

Состояние: готово к просмотру локально; не заявляется пиксельная идентичность эталону.
URL: http://127.0.0.1:8790/preview/diner/ и http://127.0.0.1:8790/.

Реализовано: информационный режим Diner, новый векторный логотип, волнистый заголовок,
единый синий акцент, рваные разделители, активный таб без соседних разделителей,
поиск из иконки без сдвига контента, ценники с граммовкой, 18 изолированных изображений.
В CMS: заголовок, подзаголовок, растровый логотип, режим меню, варианты цен, 14 аллергенов
и подтверждение владельцем; версии и история поддерживаются локально и в коде D1.

## Проверено

- Playwright/Chromium, эмуляция 320×760, 390×844, 768×1024, 1024×900,
  1440×1000, 1920×1080, 2560×1440, 3840×2160: Diner без горизонтального переполнения.
  Читаемая область на больших экранах ограничена 1200 px. Реальных устройств не было.
- Поиск «beef»: одна карточка, сдвиг категорий 0 px. Escape закрывает поиск.
- Диалог блюда по центру; Escape закрывает его. Иконки аллергенов открывают подсказки
  по нажатию; подсказки удерживаются в границах viewport.
- Информационный Diner не показывает корзину, избранное и добавление.
- Street Food и Pizzeria: добавление кнопкой и открытие корзины работают на 390 px,
  без JS-ошибок и переполнения. Проверена общая механика, не реальная отправка заказа.
- CMS: новая форма и редактор проверены на 320, 390, 768, 1440, 3840 px.
  В редакторе 14 чекбоксов, Escape закрывает неизменённый редактор.
- Через интерфейс сохранены два примерных варианта Classic Beef (80/150 г) в локальной
  базе; перед этим создана игнорируемая SQLite-копия. Другие данные не сбрасывались.
- Заголовок, подзаголовок и загрузка логотипа проверены в отдельной временной базе.
- Шесть ценовых вариантов и длинный заголовок проверены подменой ответа только в браузере,
  без записи в рабочую базу; группа ценников переносится на два ряда.
- npm run build, npm test (88/88), check:public и check:media прошли.
- Worker: сборка и wrangler deploy --dry-run; серверный deploy не выполнялся.
- Исправлен реестр происхождения: SHA-256 34 ресурсов сверены с фактическим dist;
  импортированные Astro-ресурсы теперь проверяются по хешу содержимого. Исключения
  публикации не менялись. Это техническая проверка происхождения, не юридическое заключение.

## Ограничения / следующий этап

- Подтверждения аллергенов владельцем пока нет: исходные отметки взяты только из явно
  записанных текстовых сведений, интерфейс помечает их как неподтверждённые.
- Два размера котлеты — примеры данных для просмотра, не цены настоящего заведения.
- Варианты цен пока относятся к информационному Diner. Демозаказ использует основную
  цену; выбор вариантов в корзине и настоящая отправка на кухню не реализованы.
- Локальная база сохраняет существующие 24 продукта; новый seed со всеми пиццами
  автоматически поверх неё не загружается. Публичный статический seed содержит 28 продуктов.
- Новые серверные функции ещё не опубликованы в Cloudflare. Push не обновляет D1/CMS.
- Редизайн пиццерии и поиски остальных сайтов портфолио не входят в завершённый этап Diner.
