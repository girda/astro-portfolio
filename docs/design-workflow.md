## Источники
Lindenhof реализован в `apps/lindenhof`. Токены находятся в `src/styles/global.css`, компоненты — в `src/components`. Макет содержит десктопную и мобильную страницы и UI Kit.

Портфолио находится в `apps/portfolio`. В Figma перенесены редактируемые тексты, векторы, блоки и контентные изображения. Для редактирования согласован Arimo вместо недоступного Avenir Next; моноширинные надписи — Cousine. Шрифты самого сайта не менялись. Анимации и рабочая логика остаются в коде. Автоматической двусторонней синхронизации нет: изменения сначала согласуем, затем переносим и проверяем на двух размерах.

## Публикация
`npm run build` собирает портфолио и пять демосайтов. GitHub Actions публикует `dist` в Pages. Lindenhof: `/astro-portfolio/demos/lindenhof/`, локально порт 4326.

Форма Lindenhof — демонстрационная, ничего не отправляет. Подбор авто локальный, без подключённого ИИ; сравнение и дополнительные разделы помечены как разрабатываемые. Источники медиа и лицензии описаны в README приложения.
