# Street Food

Отдельное Astro-приложение. `npm run dev -- --background` из каталога app, порт 4334. Production base: `/astro-portfolio/demos/streetfood/`.

## Каталог

`src/data/catalogue.json` — единый исходный каталог: шесть товарных категорий, 24 продукта и extras. `categoryId` связывает продукт с категорией. Цены — целые евроценты; время — минуты. «Все» и «Избранное» создаются как фильтры, а не записи категорий.

`catalogue-contract.mjs` проверяет данные. `menu-view.mjs` создаёт представление меню: скрывает отключённые категории/продукты, добавляет текущий BASE_URL к локальным изображениям. `menu.ts` подключает это к Astro. Публичная сборка использует только исходный JSON, не SQLite.

`src/scripts/cart.mjs` — расчёт/нормализация корзины. `src/scripts/menu.ts` — UI, локальное хранилище после действия, фильтры, поиск, избранное, диалоги и перелёт товара. Данные читаются из безопасно встроенного JSON текущей страницы. `preview-menu.ts` обновляет карточки только в локальном CMS-предпросмотре, используя существующий шаблон.

## Локальная CMS

Из корня проекта: `npm run build`, затем `npm run cms`. Админка: http://127.0.0.1:8790/, предпросмотр: http://127.0.0.1:8790/preview/.

SQLite исключена из Git. Правки в CMS не меняют JSON в репозитории и не публикуются на GitHub Pages. Описание первой версии и ограничений: `apps/menu-cms/README.md`.

## Демонстрационный режим

Заказы не отправляются, оплата не подключена. QR-код впоследствии может ссылаться на меню конкретного стола/филиала; настоящая кухня и заказы потребуют отдельного backend-сценария.

Фото блюд локальные, созданные для демо; происхождение и ограничения — в `docs/MEDIA_PROVENANCE_2026-10-30.json`. Изображения иллюстративны. Рецептуры/аллергены и цены перед реальной работой подтверждает заведение. При ошибке загрузки используется локальный SVG fallback.
