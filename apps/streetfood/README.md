# Street Food

Отдельное Astro-приложение: `npm run dev -- --background`, порт4334. Productionbase `/astro-portfolio/demos/streetfood/`.

`src/data/menu.ts` — 24 позиции, категории, примерные цены в центах, аллергены и extras. `src/scripts/cart.mjs` — нормализация и расчёт корзины, покрыты тестами. `menu.ts` — UI, локальное хранилище, анимация перелёта, фильтры, поиск, избранное и native-dialog.

Заказы не отправляются, оплата не подключена. QR-код впоследствии может ссылаться на URL конкретного стола/филиала; настоящая кухня и оплата потребуют backend.

Временные фотографии загружаются по публичным URL референса khlebniy.com.ua и Unsplash; права на перепродажу этих изображений не подтверждены. До клиентского запуска заменить их собственными/лицензированными фотографиями и подтвердить рецептуры/аллергены. Некоторые фото иллюстративны. При недоступности — локальный SVGfallback.
