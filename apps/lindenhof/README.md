# Autohaus Lindenhof

Демонстрационный автосалон HIRDA на Astro. Язык интерфейса: немецкий.

## Запуск

Node.js 24+, `npm ci`, `npm run dev` → http://localhost:4326/ .
Сборка: `npm run build`. В монорепозитории общая сборка публикует приложение в `/astro-portfolio/demos/lindenhof/`.

## Реализовано

Адаптивная страница по Figma, фильтры, свайп и перетаскивание карточек мышью, плавный zoom при hover, локальное избранное, вкладки с управлением клавиатурой, мобильная навигация, модальные окна, видео с управлением и учётом reduced motion, схема расположения демофилиалов. Код доступен с клавиатуры; диалоги используют нативный `<dialog>`.

Форма не отправляет данные: после проверки полей явно показывает уведомление о деморежиме. Сравнение до трёх моделей работает; будущие разделы открывают окно «в разработке». Подбор автомобиля — локальная интерактивная демонстрация; модель ИИ и backend не подключены. Нет секретов, аналитики и обращений к localhost в production.

## Дизайн

Figma: https://www.figma.com/design/Bvf3Rv1rrJzvguzR7rGst9 (Website и UI Kit).
Токены: `src/styles/global.css`. Переиспользуемые компоненты: `src/components`.
`InputField.astro` — адаптация семантики InputField/TextareaField из Simple Design System под Astro; React-компоненты из Figma нельзя напрямую использовать в приложении без React.

Салон, люди, изображения машин и дополнительные ракурсы созданы/обработаны ИИ. Не подтверждают наличие автомобилей или связь с производителями. Реальные марки используются для демонстрационных примеров. Цены и реальные предложения не заявлены.

Видеоролик: Yaroslav Shuraev / Pexels, https://www.pexels.com/video/aerial-view-of-car-driving-along-coastal-road-5418130/ . Лицензия: https://www.pexels.com/license/ . Иконки Lucide (ISC), шрифт DM Sans (OFL); лицензии в `public/assets`.
Карта OpenStreetMap/Leaflet подключается после кнопки и может быть скрыта. Три точки — реальные ориентиры Мюнхена, не филиалы Lindenhof; маршруты открываются в Google Maps. Общая информация о деморежиме не подтверждает наличие реального бизнеса.
