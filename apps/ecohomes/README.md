# Eichenhain — Häuser & Energie

Немецкий демосайт деревянных домов и энергосистем. Фиктивный бренд, модели, площади и адрес.

## Запуск
`npm ci` и `npm run dev -- --background` — http://localhost:4328/ . Порт 4327 занят другим процессом, он не останавливался.
Сборка `npm run build`; общая сборка монорепозитория публикует сайт по `/astro-portfolio/demos/ecohomes/`. Изменения сейчас только локальные.

## Структура
`src/pages/index.astro` — секции и демонстрационные данные. `src/scripts/site.ts` — фильтрация домов, детали, локальное избранное, вкладки энергосистемы, подбор модели, демоформа и FAQ. `src/styles/global.css` — брендовые стили. Общие иконки, шрифты и паттерны в `../../packages/ui`.

## Что работает
Фильтры каталога, открытие описания модели, запоминание избранного в localStorage, клавиатура в табах, переход к консультации с выбранной моделью, рекомендации по трём вариантам потребностей, локальная сводка формы. Все данные формы остаются в браузере. Подбор не использует ИИ.

## Медиа
Три авторские визуализации созданы встроенным imagegen и оптимизированы в WebP: `public/images/lichtung.webp`, `wiesenblick.webp`, `hain.webp`. Это концепты, а не фотографии построенных объектов. Обещаний экономии, сертификации или финансирования нет. Иконки Lucide ISC; DM Sans OFL.
