# Falkenried — Hausbau

Немецкий демонстрационный сайт индивидуального строительства. Композиция главной и каталога основана на визуальном референсе stroy-kotedj.ru, но фотографии, название, знак и тексты подготовлены для нашего проекта. Не используется код или контент оригинального застройщика.

## Запуск

Из корня репозитория: `npm ci --prefix apps/hausbau`, затем `npm run dev --prefix apps/hausbau`. Адрес: http://localhost:4332/. Node.js >=24.

- `/` — главная, подбор в четыре шага, услуги и подготовка обращения.
- `/katalog/` — фильтры, поиск, сортировка, избранное и сравнение до трёх домов.
- `/haeuser/<id>/` — шесть страниц домов со схематической планировкой.

## Где менять

- `src/data/houses.json` — модели, площадь, этажность, спальни, санузлы, материалы, стиль, крыша, фотографии и описания.
- `src/data/catalogue.ts` — чистая функция фильтрации и числовой сортировки. OR внутри группы и AND между группами.
- `src/scripts/catalogue.ts` — URL, форма и мобильный фильтр. Параметры: material, floors, bedrooms, style, roof, min, max, q, sort.
- `src/scripts/site.ts` — диалоги, сравнение, избранное, GSAP и подбор. Сравнение и избранное сохраняются только в localStorage этого браузера.
- `src/styles/global.css` — тема и адаптивность. GSAP появляется однократно без искусственной задержки; reduced motion учитывается.
- `astro.config.mjs` — SITE_URL / SITE_BASE. Корневая сборка задаёт GitHub Pages base автоматически.

## Границы

Формы показывают локальное подтверждение без отправки/сохранения контактов. Нет серверного API, ключей, цен, обещаний строительства и вымышленных отзывов. Сайт noindex,follow как демонстрация. Для реального клиента потребуются подтверждённые данные, правовые страницы и согласованный канал отправки.

DEV-only скрипт импорта Figma в Layout запускается только при специальном figmacapture hash; в production его нет.

Проверки: `npm test --prefix apps/hausbau`; из корня `npm test`, `npm run build`, `npm run check:seo`.
